# orders-node

A Node/TypeScript service generated by `eventpilot init`/`generate`, with every feature
turned on: DLQ, Outbox, and the SDK reporting traces to the control plane.

Generated from [`eventpilot.yaml`](./eventpilot.yaml) — regenerate it yourself with:

```bash
eventpilot generate --force
```

## Running it

```bash
eventpilot up                              # starts Redpanda + Postgres
cd services/order-service
npm install
npm run dev                                 # starts the producer/consumer
```

In another terminal, from this directory:

```bash
eventpilot dashboard                        # see the live graph, metrics, replay
```

## What's in `services/order-service/`

- `src/producer.ts` / `src/consumer.ts` — wrapped with `@pilotevent/sdk-node`, so every
  produce/consume (and consumer error) is reported to the control plane automatically.
- `src/dlq.ts` — retry-with-backoff + dead-letter helper (`features.dlq` in the YAML).
- `src/outbox.ts` / `src/outbox-relay.ts` — the Outbox pattern (`features.outbox`): write
  events inside your own DB transaction via `writeOutbox`, and `startOutboxRelay` delivers
  them to the broker asynchronously.
