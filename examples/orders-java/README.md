# orders-java

A Java service generated by `eventpilot init`/`generate`, with every feature turned on:
DLQ, Outbox, and the SDK reporting traces to the control plane.

Generated from [`eventpilot.yaml`](./eventpilot.yaml) — regenerate it yourself with:

```bash
eventpilot generate --force
```

## Running it

```bash
eventpilot up                              # starts Redpanda + Postgres
cd services/payment-service
gradle run
```

In another terminal, from this directory:

```bash
eventpilot dashboard                        # see the live graph, metrics, replay
```

## What's in `services/payment-service/`

- `*Producer.java` / `*Consumer.java` — report produce/consume/error traces via
  `EventPilotAgent.java`. Not a Maven Central dependency (no Sonatype account set up to
  publish there yet) — it's generated straight into the project instead, same as the
  rest of the code here.
- `Dlq.java` — retry-with-backoff + dead-letter helper (`features.dlq` in the YAML).
- `Outbox.java` / `OutboxRelay.java` — the Outbox pattern (`features.outbox`), using
  plain JDBC: write events inside your own DB transaction via `Outbox.writeOutbox`, and
  `OutboxRelay` delivers them to the broker asynchronously.
